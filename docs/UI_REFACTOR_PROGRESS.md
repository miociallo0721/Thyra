# UI 重构进度

更新：2026-09-25。依据 `UI_REFACTOR_PLAN.md` 实施，未修改 Memoh API 协议或流式事件归并逻辑。

## 已完成

- 设计系统固定浅色主题，采用鼠尾草绿、暖白和语义错误色；补齐排版、动效 token 与 API 26 可用的静态半透明表面。系统状态栏和导航栏使用浅色样式。
- 连接首页优先展示 Memoh Cloud 与最近服务器；新增自托管服务器进入聚焦表单。认证区分 Cloud 验证码、密码和访问令牌，并在操作附近显示忙碌与错误状态。
- Agent 与会话列表补充状态、不可用说明、更新时间、明确选中态、空态操作和整行读屏语义。会话列表使用可保存的滚动状态。
- 宽屏会话栏按窗口宽度设置上下限，并在大字设置下退回单栏；未选会话时展示 Agent 身份与新建引导。
- 聊天顶栏显示服务器、Agent、会话及连接状态；历史加载、真正空内容和连接错误分别呈现，错误可重试且保留现有转录。
- 已保存账号的启动恢复设置 15 秒超时；超时后显示可返回切换服务器的认证页提示，避免一直停在启动指示器。
- 草稿按服务器、Agent、会话隔离，保存在 `SavedStateHandle` 中；密码、令牌和验证码没有进入可恢复状态。
- 导航保留共同返回栈前缀，避免返回时重建列表；手机导航和局部展开使用短动效。初次历史直接定位底部，新消息平滑滚动，流式增量直接维持底部，用户上滑后不强制拉回。
- 工具输入与输出保留完整查看、选择和复制路径，推理与工具活动默认折叠。
